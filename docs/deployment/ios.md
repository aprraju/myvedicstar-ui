# iOS

Built and released independently of the web SPA.

## Local development

Prerequisites: macOS, Xcode (current), iOS simulators, Node 24.

```bash
npm ci
npm run mobile:ios              # Expo dev server + iOS simulator (API at http://localhost:5275)
```

Native project: generated by `npm run prebuild -w @myvedicstar/mobile` (git-ignored). Builds can also run on EAS from
Windows/Linux — a Mac is only needed for local simulator work.

## Builds (EAS)

```bash
npx eas build --platform ios --profile preview       # internal distribution / TestFlight
npx eas build --platform ios --profile production
npx eas submit --platform ios --profile production   # App Store Connect
```

Signing: EAS-managed distribution certificate and provisioning profile, or credentials from the CI secret store with an
App Store Connect API key. **Never commit** `.p12`, `.p8` or `.mobileprovision` files (git-ignored).

## Configuration notes

- Bundle identifier per environment (`com.myvedicstar.app`, `.staging`, …) from `app.config.ts`.
- `supportsTablet: true`, `requireFullScreen: false` (iPad Split View / Slide Over / Stage Manager).
- `NSLocationWhenInUseUsageDescription` explains location use (location feature, Phase 2).
- Tokens (Phase 2) in the Keychain via `expo-secure-store`.

## Device coverage

iPhone SE (small), iPhone 16/17 (standard), Pro Max (large), iPad (portrait/landscape, Split View), with Dynamic Type at
the largest accessibility sizes and VoiceOver.

## Mobile E2E

Maestro flows (see [android.md](android.md)) on iOS simulators — iPhone and iPad — where macOS CI runners are available.
