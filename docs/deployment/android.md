# Android

Built and released independently of the web SPA. A web deployment never requires a new binary; a mobile release never
requires a web deployment (unless a shared API contract change needs both).

## Local development

Prerequisites: Node 24, Android Studio (SDK, emulator), JDK 17+.

```bash
npm ci
npm run mobile:android          # Expo dev server + Android emulator (API at http://10.0.2.2:5275)
```

Native project: generated by `npm run prebuild -w @myvedicstar/mobile` (git-ignored).

## Builds (EAS)

| Profile (`apps/mobile/eas.json`) | Use                                        | Environment    |
| -------------------------------- | ------------------------------------------ | -------------- |
| `development`                    | internal testing builds                    | local API      |
| `preview`                        | internal distribution (QA)                 | staging API    |
| `production`                     | Play Store AAB, auto-increment versionCode | production API |

```bash
npx eas build --platform android --profile preview
npx eas build --platform android --profile production
npx eas submit --platform android --profile production
```

Signing: EAS-managed upload keystore (or one stored in the CI secret store). **Never commit keystores**
(`*.jks`, `*.keystore` are git-ignored). Play App Signing is enabled on the store listing.

## Device coverage

| Class                   | Emulator (AVD)                                                                                           |
| ----------------------- | -------------------------------------------------------------------------------------------------------- |
| Small / large phone     | Pixel 4a, Pixel 8 Pro                                                                                    |
| Tablet                  | Pixel Tablet (portrait + landscape)                                                                      |
| Foldable                | "7.6" Fold-in with outer display" AVD and Pixel Fold — test folded, unfolded, and fold/unfold at runtime |
| Freeform / split-screen | Resizable emulator; multi-window                                                                         |

## Mobile E2E — Maestro (recommended)

Maestro (YAML flows, no app instrumentation, works for Android emulators and iOS simulators, simple CI) is preferred
over Detox (heavier native test harness, gray-box synchronisation). Flows live in `apps/mobile/e2e/*.yaml` from
Phase 2; run on Android phone, tablet and foldable AVDs in CI where emulators are available.

## Pipeline

`.github/workflows/mobile.yml`: install → lint → typecheck → Jest tests → `expo export` (Metro bundle for Android
and iOS) → EAS build (manual trigger, requires `EXPO_TOKEN` secret) → store submission through the approved release
process.
